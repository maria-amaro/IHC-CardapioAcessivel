# Checklist de Entrega

## Código
- [ ] Repositório Git com histórico de commits.
- [ ] Frontend instala, inicia e compila.
- [ ] Backend instala, inicia e compila.
- [ ] README explica os comandos de execução.

## Documentação
- [ ] Projeto escrito revisado e coerente com o que foi realmente feito.
- [ ] Requisitos funcionais e não funcionais registrados.
- [ ] Rastreabilidade entre requisitos e evidências.
- [ ] Fontes bibliográficas citadas.

## Pesquisa e avaliação
- [ ] Consentimento aplicado quando houver participantes.
- [ ] Entrevistas e observações identificadas como dados reais, se realizadas.
- [ ] Dados de exemplo claramente identificados como simulados.
- [ ] Avaliação heurística registrada com evidências e severidade.
- [ ] Testes de usabilidade e SUS reportados somente se efetivamente realizados.
- [ ] Melhorias relacionadas aos achados de avaliação.

## Apresentação e submissão
- [ ] Slides incluem problema, método, solução, avaliação e conclusão.
- [ ] Demonstração do fluxo principal ensaiada.
- [ ] Capturas legíveis e legendadas.
- [ ] Relatórios, prompts e evidências incluídos quando exigidos.
- [ ] Arquivos finais conferidos antes da submissão no Moodle.
